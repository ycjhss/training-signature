## 원인 분석 `SyntaxError: Unexpected token '<'` 에러는 **Code.gs가 아닌 index.html 쪽 문제**입니다. 원인은 다음과 같습니다. **index.html에서 `fetch`로 GAS API를 호출할 때**, GAS가 실제 JSON 대신 **HTML 오류 페이지**(`…`)를 응답으로 돌려보내는데, 이걸 `res.json()`으로 파싱하려다가 `<` 문자에서 터지는 것입니다. 주요 원인 두 가지: 1. **`Content-Type: application/json` 헤더** — GAS는 이 헤더가 있으면 preflight(CORS) 오류를 내며 HTML 오류 페이지를 반환합니다. **반드시 제거하거나 `text/plain`으로 설정해야 합니다.** 2. **배포 설정 오류** — "액세스: 나만" 으로 배포하면 로그인 HTML 페이지가 반환됩니다. **반드시 "모든 사용자(익명 포함)"로 배포해야 합니다.** --- ## ✅ Code.gs (완성본 — 에러 수정) ```javascript /* ================================================ 백송고 연수 서명 시스템 - Code.gs 완성본 ================================================ */ const ADMIN_PIN = '002574';
